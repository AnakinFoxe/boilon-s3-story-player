# 电量估算的依据

固件屏幕上的电量是**按电压估算**的百分比，算法在
[`m2_battery_estimate.h`](../../main/boards/boilon-s3-gen2/m2_battery_estimate.h)（主机测试 `test_m2_battery`）。参数与原厂固件
2.0.5 一致，来自 2026-10 对原厂应用的静态分析：原厂用乐鑫的 `adc_battery_estimation` 组件，下面的分压电阻、电压表和滤波系数
是从它的配置和代码里读出来的，不是拆机测量，也没有对电池真实容量做过校准。

## 电压

- 电池经分压接到 GPIO4（ADC1 通道 3）；原厂的共享 ADC 初始化也是这样标的。GPIO5 是另一路 VBUS 输入，本固件不用。
- 分压电阻：上 200 kΩ、下 100 kΩ，`divider_ratio = 100k / (200k + 100k)`。
- 电池电压 = 校准后的引脚电压 ÷ ratio，即 **电池 mV = 引脚 mV × 3**。
- 校准不可用、读数无效时，电量显示未知（`--%`），不拿原始 ADC 码当电压。

## 百分比

原厂的电压表有 7 行，相邻两点之间线性插值；高于 4.20 V 取 100，低于 3.00 V 取 −10：

| 电池电压 V | 原厂容量值 % |
| --- | --- |
| 4.20 | 100 |
| 4.06 | 80 |
| 3.82 | 60 |
| 3.58 | 40 |
| 3.34 | 20 |
| 3.10 | 0 |
| 3.00 | −10 |

第一次读数直接采用，之后 `新值 = 0.2 × 本次 + 0.8 × 上次`。原厂另外按充放电状态限制反向变化；本固件测不出是否在充电（不能凭
USB 连接推断），所以没有这一步。显示前钳制到 0–100，原厂表里的负值不会显示出来。

## 局限

这条电压曲线不是库仑计：充电、播放负载和电池老化都会影响估算，不能据此推算剩余分钟数。低电量提示与关机的规则见
[板子说明](../../main/boards/boilon-s3-gen2/README.md)「播放器」一节。
