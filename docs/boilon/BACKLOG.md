## 2026-10-15 提过、这次没选的播放器功能

做播放模式时一起讨论过，用户这次只选了语音暂停和语音关机：

- **睡眠定时**：「20 分钟后停」「放完这集就停」，到点声音渐弱、暂停并保存，之后照常闲置自动关机。循环、单曲和随机模式下
  故事不会自己停，也就不会闲置关机，晚上用这些模式时最需要它。
- **跳过片头**：按目录记一个秒数，从头开始的文件直接从那里放。
- **熄屏**：声音照放、按任意键亮屏；睡前不亮，也省电。
- **音量上限**：设备分不清是谁在说话，孩子也能让喵喵把上限调高；要管用，得让「调高上限」只能用按键组合。

## 2026-10-16 让喵喵清除播放进度（做法已定，暂缓）

想要的：对喵喵说「把西游记的进度清掉」「把所有进度都清掉」，相应的断点记录删掉，音频又从头开始放。用户定的做法：

- **范围**：单个目录，或者全部（整台机器的断点记录）。某一集单独从头放，用现有的「第 N 集从头放」。
- **正在听的目录被清掉时**：喵喵说完这句，对话结束，这个目录从第一个文件的开头放，和点播第 1 集一样。
- **先确认**：喵喵复述要清什么、对方说好才清，因为清掉的进度找不回来。
- 音量和播放模式不算进度，不清。

做的时候要注意：

- 「全部」不能写一张空表：断点表 `bl_resume/state_v2` 的格式把 0 条当成损坏，旧版本读到它就再也存不了进度。要删掉这条
  NVS 记录，连同更早格式的 `state_v1` 一起删，否则 v2 没了会退回去读 v1 里的旧位置。单个目录清完若一条不剩，也这样办。
- 对话中故事是停着的，对话结束切走时还会为刚才那一集存一次位置（`kCollectionChange` 检查点）。清除要排在这次存盘之后，
  并且不再为旧位置存盘，否则刚清的那一集马上又被记回去。
- NVS 只在断点线程里写：加一种队列任务；同时清掉播放器内存里记着的位置、断点线程的位置缓存，以及续播策略缓存的「上次已存」
  记录，否则下一次内容相同的存盘会被当成没变而跳过。
- 按流程做：合同 → 主机测试 → USB 联调（测试版的版本名低于正式版）→ PR → 发 v1.4.0。
